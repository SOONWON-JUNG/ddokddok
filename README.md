# 똑똑 (ddokddok)

> “똑똑. 교수님, 저희 왔어요!”
> 동의대학교 제14대 총장으로 취임하신 전경란 교수님께 제자들이 드리는 축하 웹게임.
> 20년 전 늘 두드리던 702호 문으로 돌아가는 작은 여행. 체험 시간 약 5~7분 · 아이패드/PC 웹브라우저.

## 이야기 흐름

`본관 앞(2026년)` → `겁먹은 신입생 · 수풀 속 강아지(이후 졸졸 따라다님)` → `비탈길을 내려가며 과거로(계절·연도 변화)` → `수덕전 · 딸기파르페 · 추억 포인트` → `산학협력관 앞 피자 배달 이벤트(2006년)` → `복도 게시판 · 포스터 · 박성대 교수님과 창현 병아리` → `702호 똑똑 · "네, 들어오세요!" · 아무도 없는 연구실` → `책장 · 이상한 달력 · 빨간 펜 과제 첨삭 · 보물 힌트` → `강아지가 파낸 비밀 정원 대문` → `병아리 제자들이 사람으로 · 보물상자 · 실제 선물` → `엔딩 크레딧` → `쿠키 영상`

## 시작하기

```bash
npm install      # 처음 한 번
npm run dev      # 개발 서버: http://localhost:5173 (아이패드는 터미널의 Network 주소)
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 (코드를 고치면 화면이 자동으로 바뀜) |
| `npm run typecheck` | 오류 검사 |
| `npm run build` | 배포용 파일을 `dist/` 에 만듦 |
| `npm run build:single` | 인터넷 없이 열리는 백업 `dist-single/ddokddok.html` 생성 |
| `npm run preview` | 만들어진 `dist/` 를 미리 보기 (같은 와이파이의 아이패드에서도 접속 가능) |

## 조작

- **아이패드/PC 화면**: 가고 싶은 곳을 탭(클릭)하면 걸어갑니다. 사람·문·물건을 탭하면 다가가서 말을 걸거나 살펴봅니다.
- **키보드**: 방향키 또는 WASD 로 이동, `Space` / `Enter` / `E` 로 대화·상호작용·넘기기
- 대화 선택지: 탭, 숫자키(1·2), 방향키(↑↓) + Enter
- 오른쪽 위 🔊: 소리 켜기/끄기
- 진행은 자동 저장됩니다. 새로고침해도 타이틀의 "이어하기"로 이어집니다.

## 기술

Phaser 3 + TypeScript + Vite. 그림은 모두 코드로 그린 도트(이미지 파일 없음)이며, 사진·음원은 `public/` 폴더에 파일을 넣으면 자동으로 바뀝니다. 배경음악은 퍼블릭 도메인/CC0 클래식 연주(`public/audio/README.txt`), 효과음은 Web Audio 로 합성합니다.

`main` 브랜치에 올리면 GitHub Actions 가 빌드해서 GitHub Pages 에 자동으로 배포합니다 (`.github/workflows/deploy.yml`, 자세한 내용은 [docs/DEPLOY.md](docs/DEPLOY.md)).
