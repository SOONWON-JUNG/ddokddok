## 1. 기술 방향 (오픈형 픽셀 RPG 방식으로 변경)

| 항목 | 제안 | 이유 |
|---|---|---|
| 엔진 | **Phaser 3 + TypeScript + Vite** | 타일맵, 충돌, 카메라, 터치 입력, 애니메이션을 기본 제공. 아이패드 Safari 지원이 검증됨 |
| 시점 | **탑다운 3/4 쿼터뷰**(포켓몬·어스바운드식). 진짜 아이소메트릭은 사용 안 함 | 진짜 아이소는 제작·충돌 처리가 훨씬 복잡. 12페이지 느낌은 쿼터뷰 아트로 충분히 냄. 대각선 길은 충돌 영역으로 처리 |
| 해상도 | 논리 해상도 640×480(4:3), `pixelArt` 렌더링으로 선명하게 확대 | 아이패드 비율, 픽셀이 뭉개지지 않음 |
| 조작 | **아이패드**: 화면 탭(탭한 곳으로 자동 이동) + 키보드 방향키. **PC**: 마우스 클릭 + 키보드(방향키/WASD, 스페이스·엔터로 대화). NPC/오브젝트는 탭하면 다가가서 상호작용 | 교수님이 게임에 익숙하지 않아도 쉽게 조작. 5~7분 안에 끝나는 체험에 적합 |
| 맵 | 맵 데이터는 Tiled 형식(JSON). 장면 로직·대사는 별도 `data/*.json` | 대사·위치 수정을 코드 없이 가능 |
| 진행 | **퀘스트 플래그 방식**: 자유롭게 돌아다니되 핵심 이벤트는 순서대로 열림 + 화면 상단에 "다음 목표" 힌트 | 오픈 느낌과 5~7분 완주를 동시에 만족 |
| 사운드 | BGM 1~2곡 + 효과음(노크, 종이, 상자 개봉), 첫 터치에서 시작 | iOS 오디오 제한 대응 |
| 배포 | 정적 호스팅(Netlify/Vercel/GitHub Pages) + 오프라인 백업 번들 | 링크 공개라 배포 간편. 행사장 와이파이 불안 대비 |

## 2. 맵 구성 (오픈 월드 느낌, 맵 3개)

| 맵 | 내용 | 자유 탐색 요소 (선택 이벤트) |
|---|---|---|
| **A. 캠퍼스 야외** (스크롤되는 큰 맵) | 본관(시작, 현수막) → 오르막 비탈길 → 산학협력관 앞(피자 배달부) / 한쪽에 숨겨진 비밀 정원(보물상자, 과제 힌트 후 열림) | 비탈길 중앙 오른쪽 **딸기파르페 아이템**, 나무·벤치·재학생 NPC 등 추억 클릭 포인트 2~4개 |
| **B. 산학협력관 1층 복도** | DICON 화살표 + 디지털콘텐츠학과 초록 게시판, 702호 방향 안내 | 게시판 클릭 시 추억 메시지 |
| **C. 702호 연구실** | 702호 문패 + 시간표, 책상·책장·과제 더미·빨간 펜 | 책장 → 교수님 책 이미지 / 결혼식 사진 → 주례 감사·축하 글 |

핵심 동선(퀘스트): 본관 현수막 → 비탈길 오르기 → 산학협력관 앞 피자 배달 → 건물 안 게시판 → 702호 노크 → 빨간 펜·과제 → 힌트 → 비밀 정원 보물상자 → 실제 선물 → 엔딩 크레딧.

## 5. 픽셀 아트 제작 방식 (확정: B안)

세 가지 방법이 있고, 현실적으로는 **B안(무료 에셋 + 필요한 것만 AI 제작)** 을 권장합니다. 직접 그리는 방식은 하지 않습니다.

| 안 | 쉬운 설명 | 시간·비용 | 장단점 |
|---|---|---|---|
| **A. 직접 제작** | 픽셀 하나하나 손으로 그림 | 매우 큼 | 폐기 (12일 안에 불가능) |
| **B. 무료 에셋 + 필요한 것만 제작** (권장) | 땅·길·나무·벽·책상 같은 **기본 부품은 무료로 공개된 그림 세트(CC0)를 그대로 사용**. 교수님, 본관, 산학협력관, 현수막, 게시판처럼 **우리 이야기에만 필요한 몇 가지만 AI로 생성하거나 에셋을 고쳐서** 제작 | 비용 0원. 시간 가장 적음 | 전체 톤이 통일되고, 필요한 곳만 맞춤 제작 |
| **C. 전부 AI 생성** | 모든 그림을 AI로 생성 | 비용 낮음, 정리에 시간 소요 | 걷는 모션(4방향 × 여러 프레임)을 AI가 일관되게 그리기 어려움 |

핵심 이유: 걷는 캐릭터와 맵 타일은 같은 크기·같은 그림체로 수십 장이 맞아야 해서 AI만으로는 어긋남이 생깁니다. 반면 특별한 건물·아이템·사진 액자는 한 장짜리 그림이라 AI로 만들기 쉽습니다.

참고: 무료 에셋 예시(Kenney, 상업 이용 가능한 CC0 라이선스). 이 에셋은 어스바운드풍보다 포켓몬·젤다풍(위에서 내려다보는 시점)에 가깝습니다. 12페이지의 비스듬한 어스바운드 느낌은 건물·길 그림을 맞춤 제작해서 가까이 가져갑니다.
- Tiny Town: https://kenney.nl/assets/tiny-town (마을·건물·나무, 16×16)
- Roguelike/RPG pack: https://kenney.nl/assets/roguelike-rpg-pack (타일 1,700여 장, 가구·소품 포함)

**확정**: B안. 시안은 S1~S2 엔진 개발 중에 확인합니다. 남은 결정 사항 없음.

## 8. 구현 결과 (v1.1)

계획 대비 달라진 점과 최종 구성입니다.

- 3D(아이소메트릭) 디오라마는 폐기하고 2D 픽셀 쿼터뷰로 확정했습니다.
- 맵은 3개 계획에서 **4개**로 늘었습니다: 야외 / 산학협력관 복도 / 702호 연구실 / 비밀 정원.
- 진행 순서: 본관 현수막 → 비탈길(연도 2026→2006) → 수덕전·파르페·추억 포인트 → 피자 배달 이벤트 → 복도 게시판 → 702호 노크 → 연구실(과제 더미, 빨간 펜, 시간표, 책장, 결혼식 사진) → 보물 힌트로 비밀 정원 대문 열림 → 보물상자 → 엔딩 크레딧.
- 소리는 외부 음원을 내려받지 않고 코드로 합성했습니다(BGM 4곡 + 효과음). `public/audio/` 에 mp3 를 넣으면 파일이 우선합니다.
- 추가한 기능: 타이틀(시작하기/이어하기), 진행 자동 저장, 소리 켜기/끄기 버튼, 가만히 있으면 목표 문구가 반응하는 힌트 넛지, 오프라인용 서비스 워커(홈 화면 추가), 인터넷 없이 열리는 단일 HTML 백업.
- 문서: README, docs/INTELLIJ.md, docs/SOURCE_GUIDE.md, docs/CONTENT_TODO.md, docs/DEPLOY.md
