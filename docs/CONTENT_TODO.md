# 바꿔야 할 임시 문구·사진 목록 (스토리/디테일 수정용)

현재 게임의 흐름과 장치는 모두 완성되어 있고, 아래 항목은 **임시 문구/임시 그림**입니다. 이 표를 보면서 하나씩 바꾸면 됩니다.
(확정된 문구는 "확정" 으로 표시했어요.)

## 1. 대사 — `src/data/dialogues.ts`

| 키 | 장소 | 내용 | 상태 |

| `pizza` | 산학협력관 앞 배달부 | 첫 두 줄과 선택지 2개는 기획서 문구. 선택 후 반응은 임시 | 일부 확정 |

## 2. 과제 더미 첨삭 — `src/data/papers.ts`
- 3쪽 모두 임시입니다. 맞춤법·띄어쓰기 교정과 코멘트, 마지막 쪽의 **보물 힌트 문구**를 실제 이야기로 바꿔 주세요.
- 마지막 쪽 힌트는 정원 대문의 위치("비탈길 오른쪽 숲속, 장미 덩굴 대문")와 맞아야 합니다.

## 3. 사진·카드 — `src/data/cards.ts` + `public/images/`
| 파일 | 내용 | 현재 |
|---|---|---|
| `public/images/book.jpg` | 교수님 책 표지 (책장 > 저서 발견) | 없으면 도트 책 그림 |
| `public/images/sports.jpg` | 체육대회의 추억 4컷 만화 (책장) | 제공된 이미지 그대로 |
| `public/images/wedding.jpg` | 교수님과 찍은 결혼식 사진 | 없으면 도트 그림 |
| `public/images/gift.png` | 실제 선물 사진 (보물상자 속) | 없으면 도트 선물 그림 |
- 결혼식 사진 카드의 **주례 감사 인사·취임 축하 문구**(`cards.ts` 의 `wedding.text`)는 임시입니다.
- 권장 이미지: 가로가 긴 사진, 1000px 안팎, 용량은 각각 500KB 이하 (아이패드에서 빨리 열리도록)

## 4. 캐릭터 모습 (임시 도트)
- 제자 3명(현서·창현·태진): 피자 이벤트에서는 **병아리**(`CHICKS`), 보물상자를 열면 **사람 모습**(`KIDS`)으로 등장 — `src/scenes/BootScene.ts`, 얼굴 아이콘은 `src/ui/portraits.ts`(`chick_*`, `kid_*`)
- 병아리 머리 위 이름표는 `src/data/cutscenes.ts` 의 `CHICKS` 의 `label`
- 피자 배달부: 빨간 모자·재킷 — `BootScene.ts` 의 `PIZZA_PALETTE`
- 교수님: 사진을 참고한 단발 웨이브 머리, 어두운 블레이저, 흰 상의

## 5. 소리
- 지금은 코드로 만든 BGM 4곡(야외/실내/정원/엔딩)과 효과음입니다.
- 무료 음원을 쓰려면 `public/audio/` 에 `bgm_outdoor.mp3`, `bgm_indoor.mp3`, `bgm_garden.mp3`, `bgm_ending.mp3` 로 저장하세요. (파일이 있으면 자동으로 그 파일을 사용)
- 무료 음원은 **이용 조건(출처 표기 등)** 을 꼭 확인하세요.
